# Projet Produits

Un simple projet Node.js utilisant Express.js pour créer une API RESTful de base pour la gestion de produits.

## Initialisation du Frontend en JS natif

Le frontend est une application simple en HTML, CSS et JavaScript natif.

### Utilisation de l'API Fetch pour le CRUD

Le fichier `frontend/js/apiService.js` contient les fonctions pour communiquer avec l'API backend en utilisant `fetch`.
